# Silkway 丝路 —— macOS 代理客户端 UI 设计需求文档

> 基于 sing-box 内核的原生 macOS 代理客户端设计规范

---

## 1. 产品定位

一款基于 **sing-box** 内核的 macOS 原生代理客户端，目标用户为有一定技术背景的开发者与高级用户。

追求**简洁、高效、原生 macOS 体验**，区别于现有 Electron / Flutter 客户端的臃肿感。

---

## 2. 设计规范

| 项目 | 规范 |
|------|------|
| **平台** | macOS 14+（Intel & Apple Silicon） |
| **设计系统** | Apple Human Interface Guidelines |
| **窗口风格** | 以 Settings / Preferences 面板为主（类似系统设置），而非传统独立窗口 |
| **主题模式** | 深色 / 浅色双模式适配，**优先设计深色模式** |
| **字体** | 系统默认 SF Pro |
| **图标风格** | SF Symbols 线条风格为主，避免彩色拟物图标 |
| **开发语言** | Swift + SwiftUI |

---

## 3. 信息架构

```
├─ 主界面（菜单栏弹窗 / Menu Bar Extra）

│   ├─ 节点列表（可展开分组）
│   ├─ 模式切换（全局 / 规则 / 直连）

└─ 设置面板（Settings Window，Sidebar Tab 导航）
    ├─ 通用（General）
    │   ├─ 开机自启
    │   ├─ 启动时自动连接
    │   ├─ 静默启动（不显示窗口）
    │   ├─ 语言切换
    │   └─ 快捷键设置
    │
    ├─ 订阅（Subscriptions）
    │   ├─ 订阅列表（名称、地址、更新时间、节点数）
    │   ├─ 添加 / 编辑 / 删除订阅
    │   ├─ 手动更新全部
    │   └─ 自动更新间隔
    │
    ├─ 代理节点（Proxies）
    │   ├─ 节点列表（名称、延迟、协议、地区国旗）
    │   ├─ 分组视图（自动选择 / 负载均衡 / 手动选择）
    │   ├─ 延迟测速按钮
    │   └─ 筛选 / 搜索
    │
    ├─ 路由规则（Rules）
    │   ├─ 规则集列表（DOMAIN、IP-CIDR、GEOIP 等）
    │   ├─ 规则优先级排序（拖拽）
    │   ├─ 自定义规则添加
    │   └─ 规则日志 / 命中统计
    │
    ├─ DNS
    │   ├─ DNS 服务器配置
    │   ├─ DNS 模式（fake-ip / redir-host）
    │   └─ DNS 规则
    │
    ├─ 连接日志（Connections）
    │   ├─ 实时连接列表（源地址、目标、协议、流量、时长）
    │   ├─ 断开指定连接
    │   └─ 流量统计图表
    │
    └─ 关于（About）
        ├─ 版本信息
        ├─ 内核版本
        └─ 开源许可
```

## 4. 关键交互细节

| 场景 | 设计要求 |
|------|---------|
| **菜单栏弹窗** | 点击菜单栏图标弹出，类似系统 WiFi / 蓝牙面板，宽度 320–360px，支持快捷键呼出 |
| **开关状态** | 连接中要有明确的动画反馈（如脉冲光环），断开时灰色静默 |
| **节点延迟** | 用颜色区分：绿色（<200ms）、黄色（200–500ms）、红色（>500ms）、灰色（超时） |
| **测速** | 支持批量测速，进行中显示进度条，完成后刷新延迟数字 |
| **规则命中** | 连接日志中高亮显示匹配到的规则名称 |
| **流量显示** | 采用人性化单位（KB / MB / GB），保留 2 位小数 |
| **导入订阅** | 支持粘贴链接 + 拖拽配置文件到 Dock 图标 |
| **错误提示** | 使用 macOS 原生 Notification，避免弹窗打断 |

## 5.1 强调色策略（已定案）

**跟随系统强调色**（`Color.accentColor`），而非锁定品牌蓝。

设计稿中的 `#0A84FF` 是 macOS 深色模式默认强调色，仅作为**视觉参考值**；实现时必须用 `Color.accentColor`，让 UI 随用户系统设置变化。

⚠️ **例外**：状态色（成功/警告/错误/禁用）**不跟随系统**，必须锁定固定色值。否则用户把强调色设成红色时，「已连接」会变成红色 —— 语义崩塌。

## 6. 设计风格关键词

> 原生、克制、开发者工具、暗色优先、信息密度适中、动画细腻但不浮夸

## 8. 设计优先级建议

1. **P0 — 菜单栏弹窗**：最核心的日常交互入口
2. **P0 — 设置面板首页（General）**：确立整体视觉风格
3. **P1 — 代理节点页（Proxies）**：节点列表 + 测速交互
4. **P1 — 连接日志（Connections）**：实时数据展示
5. **P2 — 订阅管理 / 路由规则 / DNS / 关于**

> 建议先出 **菜单栏弹窗 + 设置面板首页** 两张图确认风格，再展开全部页面。
